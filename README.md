## 🧩 目录结构

| 目录 | 说明 |
|------|------|
| `agent/` | Agent 测试脚手架 |
| `bin/` | 可执行入口 |
| `dashboard/` | 测试仪表盘 |
| `docs/` | 文档 |
| `mcp-config/` | MCP 配置文件 |
| `memory/` | 测试用 memory 目录 |
| `packages/` | 子包（afdian-mcp / dashboard / github-api / tri-link-mcp 等） |
| `scripts/` | 运维脚本 |
| `skills/` | 测试用 skills |

git clone https://github.com/Zeon7744/tri-link-test.git

ls packages/
